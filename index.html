Назначение и обрабатываемые данные

Расширение позволяет сохранять доступные пользователю переписки из веб-версии MAX (https://web.max.ru/). После явного действия пользователя получает временный доступ к активной вкладке, считывает доступные в интерфейсе сообщения и их метаданные: имена, даты, время, текст, сведения об ответах, пересылках и вложениях, если они доступны. Текст может содержать персональные и чувствительные сведения. При включении расшифровки голосовых расширение использует встроенную возможность самого MAX и считывает результат, когда он доступен. MAX может обрабатывать аудио по своим условиям; расширение не передаёт его на сервер разработчика.

Использование, передача и хранение

Содержимое обрабатывается локально в браузере только для экспорта. Разработчик не получает переписку, не продаёт её и не использует её для рекламы. В расширении нет собственной аналитики, удалённой базы чатов или удалённого исполняемого кода. Обрабатываемые данные находятся в памяти браузера в процессе выгрузки, а готовые файлы сохраняются на устройстве пользователя через браузер. Версия 0.5.8 не сохраняет контрольные точки переписки для восстановления после перезапуска. Простая настройка закрытия информационной плашки сохраняется в localStorage сайта MAX; она не содержит переписок. Пользователь управляет своими скачанными файлами и может удалить их самостоятельно.

Разрешения

activeTab: временный доступ к активной вкладке после действия пользователя.
scripting: выполнение встроенного в расширение локального кода для чтения доступной истории в MAX и формирования архива.

Сторонние ссылки и обратная связь

Ссылки на Telegram и YouTube открываются по действию пользователя. После перехода применяются условия этих сервисов. Сообщения, которые пользователь добровольно направляет разработчику, используются для ответа на обращение. Не отправляйте приватные переписки или секреты в обращении без необходимости.

Ограниченное использование

Использование данных, к которым получает доступ расширение, соответствует требованиям Chrome Web Store User Data Policy, включая требования Limited Use. Данные используются только для заявленной функции экспорта; они не продаются, не передаются для целей, не связанных с этой функцией, и не используются для оценки кредитоспособности.
