Условия использования и ограничения MAX

1. Назначение и доступ к данным

MAX Chat Exporter — неофициальное расширение для сохранения доступных пользователю переписок, групповых чатов и каналов веб-версии MAX. Расширение работает по явному действию пользователя в активной вкладке MAX. Оно может считывать список чатов, названия, имена отправителей, даты, время, текст, сведения об ответах и пересылках, доступные мини-аватары, ссылки и сведения о вложениях. Эти данные могут включать персональную и чувствительную информацию пользователя и других участников.

В зависимости от выбранных настроек расширение получает доступные фотографии, видео, голосовые сообщения, аудио и поддерживаемые документы. При выгрузке периода может считываться доступная история для определения дат. Сохраняются сообщения, соответствующие выбранному режиму и ограничениям.

2. Обработка, скачивание и хранение

Содержимое переписок обрабатывается в браузере для формирования выбранных пользователем файлов TXT, HTML, Markdown, JSON или CSV и ZIP-архива. Поиск и навигация в сохранённом HTML выполняются локально. Вложения и доступные мини-аватары запрашиваются у MAX и используемых им доменов доставки файлов; для получения оригинальных документов и аудио могут задействоваться штатные механизмы скачивания и аудиоплеер MAX.

Содержимое сообщений и файлов не отправляется на сервер разработчика. В расширении нет собственной аналитики, удалённой базы переписок, автоматической отправки отчётов разработчику или удалённого исполняемого кода. Данные экспорта обрабатываются в памяти браузера, а готовый архив сохраняется на устройстве пользователя средствами браузера. В архиве может быть локальный отчёт об ошибках сохранения, включая технические сведения о неудачной загрузке аудио. Публичная версия не создаёт DEV-журналы и диагностические снимки DOM.

В localStorage веб-сайта MAX сохраняются выбранные настройки расширения: типы вложений, форматы, лимиты, сведения о прохождении первоначальной настройки и о закрытии информационной плашки. Эти настройки не содержат текста переписок или файлов. Пользователь может удалить их, очистив данные сайта MAX в браузере (это также может повлиять на вход в MAX и другие настройки сайта). Скачанные архивы пользователь хранит и удаляет самостоятельно. Расширение не создаёт удалённые резервные копии переписок.

3. Расшифровка голосовых сообщений

Если пользователь включает текстовую расшифровку голосовых, расширение использует встроенную функцию MAX и считывает её результат. Обработка аудио для распознавания может выполняться самим MAX в соответствии с его условиями и политикой конфиденциальности. Расширение не отправляет голосовые сообщения на собственный сервер распознавания или сторонний сервис распознавания, выбранный разработчиком.

4. Разрешения браузера

activeTab — временный доступ к активной вкладке после действия пользователя, чтобы открыть панель экспорта и прочитать доступные данные в веб-версии MAX.
scripting — запуск локальных скриптов, входящих в состав расширения, для считывания истории, получения вложений и формирования файлов. Эти разрешения не используются для сбора истории посещения других сайтов.

5. Передача данных и сторонние ссылки

Разработчик не получает содержимое переписок в результате обычной работы расширения, не продаёт эти данные и не использует их для рекламы. Для получения выбранных данных используются MAX и его инфраструктура доставки файлов. Ссылки на Telegram, YouTube, отзывы и страницу установки в Chrome Web Store, включая ссылки в экспортированных файлах, открываются только при действии пользователя. На этих сайтах действуют их собственные условия и политики.

Кнопка поддержки автора в текущей версии ведёт в Telegram. Поддержка добровольна и не является условием экспорта. Если пользователь самостоятельно отправляет разработчику сообщение, файл или сведения об ошибке, предоставленные данные используются для ответа и решения проблемы. Не отправляйте личные переписки, ключи, пароли и другие конфиденциальные сведения без необходимости.

6. Ограниченное использование данных (Limited Use)

Разработчик соблюдает ограничения Limited Use в Chrome Web Store. Данные используются только для заявленной функции экспорта и поддержки по запросу пользователя. Разработчик не продаёт данные, не передаёт их для посторонних целей и не использует для оценки кредитоспособности или предоставления кредитов.

7. Посещение страницы политики

Эта статическая страница размещается на GitHub Pages. Разработчик не добавляет на неё формы сбора данных, рекламные скрипты или аналитику. GitHub как хостинг может обрабатывать технические данные посещения согласно своей политике конфиденциальности. Посещение страницы не передаёт содержимое чатов на GitHub.

Используйте расширение только для данных, к которым у вас есть законный доступ, учитывайте права других участников и защищайте скачанные архивы: они могут содержать конфиденциальные сведения и не шифруются самим расширением.
